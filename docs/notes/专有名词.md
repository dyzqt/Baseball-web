# 棒球专有名词

这篇主要用来帮刚接触棒球的人快速看懂比赛直播、规则说明和训练内容。下面的词汇不是一次性全背下来，而是先记住最常出现的一批。

## 一、比赛与人员

| 术语 | 说明 |
| --- | --- |
| **攻方 / 进攻方** | 当前在场上击球、跑垒、争取得分的一方。 |
| **守方 / 防守方** | 当前负责投球、接球、传球和制造出局的一方。 |
| **击球员（Batter）** | 站上本垒区准备打击的人。 |
| **跑垒员（Runner）** | 已经击出安打、保送或以其他方式上垒，正在占垒的人。 |
| **投手（Pitcher）** | 负责向本垒投球的人，是防守端最核心的位置之一。 |
| **接手 / 捕手（Catcher）** | 蹲在本垒后方接球的人，负责接投手的球、指挥配球和阻止盗垒。 |
| **内野手（Infielder）** | 守备在一垒、二垒、三垒和游击位置的球员。 |
| **外野手（Outfielder）** | 守备在左外野、中外野、右外野的球员。 |
| **先发投手** | 先开始投球的投手，通常负责比赛前段局数。 |
| **后援投手** | 在先发投手退场后登板的投手。 |

## 二、垒包与跑垒

| 术语 | 说明 |
| --- | --- |
| **本垒（Home Plate）** | 击球员开始打击和跑回得分的起点与终点。 |
| **一垒、二垒、三垒** | 场上的三个垒包，跑垒员需要按顺序依次踩过。 |
| **上垒** | 成功安全到达某个垒包。 |
| **得分** | 跑垒员依次跑回本垒，完成 1 分。 |
| **盗垒** | 在投手投球或防守松动时，提前向下一个垒包推进。 |
| **滑垒** | 跑垒员为了更安全地触垒，身体贴地滑向垒包。 |
| **强制进垒** | 因为后面跑垒员已占据前一个垒包，前面的跑垒员必须向前推进。 |
| **双杀（Double Play）** | 一次连续守备动作中制造两个出局。 |
| **三杀（Triple Play）** | 一次连续守备动作中制造三个出局，非常罕见。 |

## 三、击球与打击结果

| 术语 | 说明 |
| --- | --- |
| **挥棒** | 击球员用球棒尝试击球。 |
| **安打（Hit）** | 击球后安全上垒，通常包括一垒安打、二垒安打、三垒安打、本垒打。 |
| **本垒打（Home Run）** | 球被打出场外，或在规则允许下直接绕垒回本垒得分。 |
| **一垒安打** | 击球员安全到达一垒。 |
| **二垒安打** | 击球员安全到达二垒。 |
| **三垒安打** | 击球员安全到达三垒。 |
| **全垒打** | 常和“本垒打”同义使用。 |
| **界内球（Fair Ball）** | 落在界内、比赛继续进行的球。 |
| **界外球（Foul Ball）** | 落在界外的球。 |
| **飞球** | 击出的球在落地前被防守方处理。 |
| **滚地球** | 击球后贴地滚动的球。 |
| **高飞球** | 高高飞起的球，通常给外野手更多处理时间。 |
| **触击（Bunt）** | 击球员不大幅挥棒，而是轻轻碰球，把球往前放短。 |

## 四、投球与好球区

| 术语 | 说明 |
| --- | --- |
| **投球（Pitch）** | 投手向本垒投出一球。 |
| **好球（Strike）** | 进入好球带、击球员未挥棒的有效投球，或击球员挥棒没碰到的球。 |
| **坏球（Ball）** | 没有通过好球带、且击球员未挥棒的投球。 |
| **好球带** | 位于击球员肩部到膝盖附近之间的想象区域。 |
| **三振** | 击球员累计三个好球后出局。 |
| **保送（Base on Balls, BB）** | 投手累计四个坏球后，击球员直接上到一垒。 |
| **故意四坏** | 防守方故意让击球员保送上垒。 |
| **触身球（Hit by Pitch）** | 击球员被投出的球直接碰到身体，通常可上一垒。 |
| **控球** | 投手把球投到自己想要的位置的能力。 |
| **球速** | 投球的速度，常以公里/小时或英里/小时表示。 |
| **球种** | 投手使用的不同球路，例如直球、曲球、滑球、变速球等。 |

## 五、守备动作与出局方式

| 术语 | 说明 |
| --- | --- |
| **接杀** | 防守员在球落地前直接接住，击球员或跑垒员出局。 |
| **触杀** | 防守员持球触碰跑垒员，跑垒员出局。 |
| **封杀** | 防守员持球踩垒包，使前进到该垒的跑垒员出局。 |
| **传球** | 将球从一个防守位置送到另一个防守位置。 |
| **补位** | 防守球员移动到需要接球、接应或封杀的位置。 |
| **失误（Error）** | 防守动作出现明显错误，让进攻方受益。 |
| **双杀守备** | 通过一次守备连续完成两个出局的动作。 |
| **美技** | 难度高、观赏性强的守备动作。 |

## 六、局数、比分与比赛流程

| 术语 | 说明 |
| --- | --- |
| **局（Inning）** | 比赛的基本时间单位，一场比赛通常分九局。 |
| **半局** | 一局分为上半局和下半局，双方轮流攻守。 |
| **出局数** | 一个半局中已经被制造的出局次数。每半局 3 个出局后交换攻守。 |
| **比分** | 双方已经得到的总分。 |
| **加时 / 延长赛** | 九局结束后仍平分，继续进行的比赛局数。 |
| **完封** | 一方投手或投手群让对手整场没有得分。 |
| **再见安打 / 再见本垒打** | 在最后一攻直接结束比赛的安打或本垒打。 |

## 七、常见战术词汇

| 术语 | 说明 |
| --- | --- |
| **战术打击** | 为了推进跑垒员或制造机会而进行的打击。 |
| **牺牲打** | 让自己出局，但帮助跑垒员推进或得分的打击。 |
| **短打** | 通过触击把球打成短距离滚地球。 |
| **盗垒战术** | 利用投球时机让跑垒员向前推进。 |
| **触击战术** | 用短打制造防守混乱或推进跑者。 |
| **夹杀** | 跑垒员被两名防守球员前后夹住，进退两难。 |
| **守备布阵** | 防守方根据击球员习惯调整站位。 |

## 八、你在直播里最常听到的英文缩写

| 缩写 | 全称 | 含义 |
| --- | --- | --- |
| **AB** | At Bat | 打数，不包括保送等情况。 |
| **H** | Hit | 安打数。 |
| **R** | Run | 得分数。 |
| **RBI** | Run Batted In | 打点，帮助队友得分的次数。 |
| **BB** | Base on Balls | 保送。 |
| **SO / K** | Strikeout | 三振。 |
| **HR** | Home Run | 本垒打。 |
| **OBP** | On-Base Percentage | 上垒率。 |
| **AVG** | Batting Average | 打击率。 |
| **ERA** | Earned Run Average | 防御率，常用于评价投手。 |

## 九、看比赛时先记住这些就够了

如果你刚开始看棒球，先把下面这些词听懂，基本就能跟上比赛：

* **好球、坏球、三振、保送**
* **安打、本垒打、上垒、得分**
* **接杀、触杀、封杀、双杀**
* **局、半局、出局数、比分**

## 小结

棒球的专有名词很多，但大部分都围绕着四件事：**投球、击球、跑垒、守备**。只要先把这些基础词汇弄清楚，再去看规则、看比赛和看数据，就会轻松很多。
