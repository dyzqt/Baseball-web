# 裁判手势

看棒球时，场上发生了什么，往往先看裁判的手，再听他喊什么。

手势是给全场看的，远处看台、外野手和跑垒指导员都靠它；喊声主要给附近的击球员、捕手和投手听。很多关键判决其实是「手势 + 口令」一起完成的。

不同裁判会有自己的习惯动作，尤其是三振，但含义是一样的。下面按看比赛最常用的来记。

## 场上有哪些裁判

一场比赛通常会有 1 到 6 名裁判：

| 位置 | 也叫 | 主要管什么 |
| --- | --- | --- |
| **主审** | 司球、本垒审 | 站在捕手后方，判好球坏球、本垒攻防、开始和暂停 |
| **垒审** | 司垒 | 站在一垒、二垒或三垒附近，判跑者出局还是安全 |
| **线审** | 司线 | 站在外野边线附近，帮看法点球、本垒打 |

业余和学校比赛常见 1 到 2 人；职业比赛通常至少 4 人（1 名主审 + 3 名垒审）。

| 判决 | 手势 | 常喊的 | 含义 |
| --- | --- | --- | --- |
| **好球** | 右手握拳上举，或向右指出 | Strike / 好球 | 这球算一好 |
| **坏球** | 一般不做手势 | Ball / 坏球 | 这球算一坏 |
| **出局** | 右手握拳高举 | Out / 出局 | 击球员或跑者出局 |
| **安全** | 双臂平伸，掌心向下 | Safe / 安全 | 跑者安全上垒，或球没接稳 |

## 投球时看主审

主审蹲在捕手后面，每一球都会给一个结果。

### 好球 Strike

常见两种动作：

- 右手握拳，小臂抬到肩高，像捶门；
- 右手抬到肩旁，再向右甩出，食指指向右侧。

看球判好（击球员没挥棒）时，主审通常会大声喊 **Strike**。挥棒落空时，常常只做手势、不喊，避免和场上其他声音搅在一起。

### 坏球 Ball

坏球**通常没有手势**，主审只喊 **Ball**。没有动作本身就是信号：不是好球。

四个坏球后击球员保送上一垒。这时主审一般也不会专门指向一垒，只报球数；如果击球员没动，再提醒他「已经四个坏球了」。

### 报球数

没有记分牌，或关键球之后，主审会举起双手报当前球数：

- **左手** = 坏球数
- **右手** = 好球数
- 口头先报坏球，再报好球，例如「2 坏 1 好」

满球数是 3 坏 2 好。正规报法不会说成「二十二」或只喊「满球」。

### 开始或继续 Play

死球之后（界外、暂停、触身球等），球不会自动变回活球。投手站上投手板、捕手也准备好了，主审会：

- 右手指向投手；
- 喊 **Play** 或 **Play ball**。

没听到这声之前，投手不该出手。

如果击球员还没站好，主审会举起手、掌心朝向投手，意思是「先别投」。这等于暂时把比赛停住，之后仍要再喊 Play 才继续。

## 跑垒时看出局还是安全

垒审（有时是主审）会在垒包附近给出这两个手势。

### 出局 Out

右手握成锤状，迅速向上或向前一击，常喊 **Out**。

近身触杀时，有的裁判会先指向被杀的跑者，再做一个更用力的出局动作。这是在「卖判决」，让全场看清楚。

### 安全 Safe

双臂先合在身前，再向两侧摊开，大致与肩同高，掌心向下。近距离或争议局面会加喊 **Safe**；一目了然的安打，有时只比手势。

争议时还可能补一句原因，例如「手套没碰到人」或「守备员脚离开垒包了」。

### 三振

第三好球的手势，常常比普通好球更大。

- **看球三振**（击球员没挥棒）：主审做好球手势后，有人会再做一个「拉弓」——右手回收、左拳前伸。这不是规定动作，是个人风格。
- **挥空三振**：多数只做出局或好球手势。

还要看捕手有没有接稳。第三好球没接住时，主审通常**只给好球手势，不直接做出局**；若球落地，还会补一个安全手势，表示击球员可以跑一垒。一垒有人且少于两出局时，规则不允许跑，这时才会直接判出局。详见 [漏接第三好球](详细规则.md#quiz-dropped-third)。

## 界内、界外和暂停

这几组动作容易混，可以记成：

- **指向场内** = 比赛继续
- **双手高举** = 死球，先停下来

| 判决 | 手势 | 常喊的 | 要注意 |
| --- | --- | --- | --- |
| **界内** | 一只手臂指向界内 | 一般不喊 Fair | 靠近边线时会连指几次 |
| **界外** | 双手高举，或顺着出界方向平伸 | Foul / 界外 | 一旦喊出，通常不能改判 |
| **暂停** | 双手高举过头，掌心向前 | Time / 暂停 | 其他裁判会跟着比、跟着喊 |

界外和暂停看起来很像，都是死球。区别靠喊声：一个是 **Foul**，一个是 **Time**。

有一名裁判喊了暂停，其他裁判通常会一起举手，避免场上有人还在跑。

## 几个特别手势

| 场面 | 手势 | 常喊的 | 意思 |
| --- | --- | --- | --- |
| **本垒打** | 右手上举，食指在空中绕圈 | 有时不喊，让手势说话 | 球出墙，击球员可以跑回本垒 |
| **场地二垒打** | 右手举过头顶，比出两根手指 | Ground-rule double | 按规则送上二垒，球是死球 |
| **内野飞球** | 右手指向天空 | Infield fly, batter is out | 击球员出局，球仍是活球，跑者可冒进。见 [内野飞球规则](详细规则.md#quiz-infield-fly) |
| **触身球** | 暂停后示意击球员上一垒 | 死球 / Time | 击球员被投球打中，通常保送一垒 |
| **投手犯规** | 指向投手 | That's a balk / 投手犯规 | 垒上跑者常因此进一个垒 |
| **进攻妨碍** | 指向犯规的人 | Time! That's interference | 进攻方妨碍守备，常见结果是出局 |
| **防守阻碍** | 指向犯规的守备员 | That's obstruction | 防守挡住跑者，随后可能送垒 |
| **接住 / 没接住** | 接住做出局手势；没接住做安全手势 | 没接住时会喊 No catch | 飞球有没有在落地前拿稳 |
| **擦棒被捕** | 右手擦过左手手背，再做好球 | 不喊 Foul tip | 球擦棒后直接进捕手手套，算好球，比赛继续 |

检查挥棒（击球员是不是「出棒了」）时，主审如果自己能判，会用左手指击球员，再右手给好球，并喊 **Yes, he went**。拿不准就会转向垒审问 **Did he go?**：垒审比好球表示出棒了，比安全表示没出棒。

## 看比赛时的速查

| 你看到 | 多半是 |
| --- | --- |
| 右手一锤或向右一指 | 好球 |
| 主审站起来，没举手，只开口 | 坏球 |
| 握拳高举 | 出局 |
| 双臂一摊 | 安全 / 没接住 |
| 双手举过头顶 | 暂停或界外，先看他喊什么 |
| 手指指向场内 | 界内，继续打 |
| 食指朝天画圈 | 本垒打 |
| 左手几个、右手几个 | 左坏右好 |
| 指向投手 | Play，可以投了；或在喊投手犯规 |

裁判之间还会用摸帽檐、比出局数这类暗号提醒搭档「现在是内野飞球局面」「注意本垒计时」等。那是给他们自己看的，观众不必逐个记住。

## 小结

先把 **好球、坏球、出局、安全** 四个手势看熟，再记住 **双手高举是死球**、**指向场内是界内**。口令里最常听到的就是：

**Strike、Ball、Out、Safe、Foul、Time、Play。**

规则本身可以再看 [棒球规则（简）](rules.md) 和 [棒球规则（详）](详细规则.md)，名词对照见 [棒球专业名词](专有名词.md)。
